# FY4X Client (Fabric source project)

This is the FY4X client source project. Implemented modules: Auto Sprint, Coordinates, FPS Graph (text), Ping Display, Speedometer, Totem Counter, Armor Status. All other entries are marked "(planned)" in the GUI and do nothing. The Region Map is a demo grid, not live data. NOT compiled or tested in Minecraft by the author of this update - build it and report any errors.

## Target environment
- Minecraft 1.21.11
- Fabric Loader 0.18.1 or newer compatible with the mod metadata
- Fabric API 0.141.1+1.21.11
- Java 21
- Gradle 8.14+ (the build downloads Loom and Minecraft/Fabric dependencies, so internet access is required)

## Build on Windows
1. Install a JDK 21 and Gradle 8.14 or newer.
2. Open this folder and double-click `build.bat`, or run it from Command Prompt.
3. After a successful build, copy `build/libs/fy4x-client-0.2.0.jar` (not the `-sources.jar`) into your Minecraft instance's `mods` folder.
4. Launch Minecraft with Fabric for **Minecraft 1.21.11** and Fabric API installed.
5. Press **Right Shift** in-game to open the GUI.

## Build on macOS/Linux
Install Java 21 and Gradle 8.14+, then run `./build.sh`. The resulting mod JAR is in `build/libs/`.

## Troubleshooting
- A JAR made by renaming a ZIP is not a compiled mod. Use the JAR generated by Gradle in `build/libs/`.
- Minecraft version, Fabric Loader, Fabric API, and Java must be compatible with the versions above.
- If Gradle fails, save the full console output; the first `* What went wrong:` section usually identifies the cause.
